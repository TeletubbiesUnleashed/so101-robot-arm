# so101-robot-arm

Building a 5-degree-of-freedom arm, plus a 6th motor for the gripper.

## Status (Last Updated: [16/09/2026])
Arm is fully assembled and calibrated. Camera mount is designed but not currently in use. Working on deriving forward kinematics by hand.

## End Goal
Assemble, calibrate, and control the arm, then build up a software layer on top: kinematics derived by hand, a custom 3D-printed part I design myself, an embedded sensor subsystem and moving over to ROS 2 eventually, all documented here as I go.
